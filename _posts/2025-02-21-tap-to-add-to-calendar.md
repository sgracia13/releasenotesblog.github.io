Yes. I'm going to brag on a new feature that will absolutely save my ass the next time an important date comes up. I hate manually creating events on my phone like the plague. When receiving a new iOS message I can now tap to create a new event in my calendar so that I never forget peoples birthdays. (I have lost friends to this so actually this might change my life). Thanks Apple. I guess.
